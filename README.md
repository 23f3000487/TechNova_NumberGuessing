# Number Guessing Game

A simple Python number guessing game where the computer chooses a random number between 1 and 100, and the user tries to guess it.

## Features

- Computer randomly selects a number between 1 and 100.
- User can enter guesses.
- Shows "Too low" when the guess is smaller than the secret number.
- Shows "Too high" when the guess is larger than the secret number.
- Counts the number of attempts.
- Displays the number of attempts when the correct answer is guessed.
- Handles invalid input without crashing.

## Technologies Used

- Python
- `random` module

## How to Run

1. Make sure Python is installed on your system.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Run the following command:

```bash
python Number_Guessing_Game.py
```

5. Enter your guess when prompted.
6. Follow the higher/lower hints until you find the correct number.
